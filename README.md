# NavFOR — Navigation Focus Objectives & Results

**NavFOR** は、階層型プロジェクト管理（**Explorer**）、日付・フェーズ両対応のガント風スケジュール管理（**Project Timeline**）、マルチタブ＆画面分割対応のエディタ（**Task / Folder Detail**）、そしてクラウド同期＋ローカル3世代自動ローテーションバックアップを備えた統合タスク・プロジェクト管理アプリケーションです。

## 1. 全体画面構成（3ペイン構成）

Dashboard（メイン画面）は、VS Code などの統合開発環境（IDE）に着想を得た **3ペイン構成** になっています。各ペインの境界線はドラッグして自由に幅を調整でき、不要な時は折りたたむことができます。

| エリア | 名称 | 主な役割 |
| :--- | :--- | :--- |
| **上部バー** | **Header & Workspaces** | ワークスペース切替、画面切替（Dashboard / Calendar / Archive / Trash / Settings）、Undo/Redo、プロジェクトフィルタ、ローカル同期ステータス表示、使い方ガイド |
| **左ペイン** | **Explorer** | 最優先の `Focus` タスク枠、期限間近アラート、および階層構造のプロジェクトフォルダ＆タスクツリー |
| **中央ペイン** | **Project Timeline** | 日付基準（カレンダー）またはカスタム期間（Phase 1〜5等）でプロジェクト横断のスケジュールを可視化・操作 |
| **右ペイン** | **Task / Folder Detail** | 選択したタスクやフォルダの詳細編集（複数タブ保持、左右・上下・2x2の最大4画面分割に対応） |

## 2. Explorer（左ペイン：階層フォルダ＆Focus管理）

左側の **Explorer** では、タスクをフォルダ（プロジェクト）およびサブフォルダの階層構造で整理できます。

### 主な機能
- **階層フォルダ管理**:
  - `ProjectA/UI/Components` のように `/` 区切りまたはフォルダ内の「サブフォルダ作成」ボタンから、何階層でもサブフォルダを作成できます。
  - **ドラッグ＆ドロップ移動**: タスクを別フォルダへドラッグして移動したり、フォルダ自体を別フォルダへドロップしてサブフォルダ化できます（Explorerヘッダー部にドロップすると最上位フォルダへ戻せます）。
- **コンテキストメニュー（`...` ボタン）＆インライン操作**:
  - フォルダやタスク右側の `...` メニューから **名前変更 (Rename)**、**新規タスク作成**、**サブフォルダ作成**、**スター (Star)**、**ピン留め (Pin)**、**複製 (Duplicate)**、**アーカイブ / ゴミ箱へ移動** が可能です。
  - **フォルダ複製**: フォルダを複製すると、配下のサブフォルダ構造とタスク一式がまとめてコピーされます。
  - **親フォルダの締切自動算出**: サブフォルダや配下タスクの締切日時から、親フォルダの直近の締切が自動的に計算・表示されます。
- **幅の調整と折りたたみ**:
  - Explorer右端の境界線をドラッグして幅を調整でき、ヘッダーの折りたたみアイコンで細いバーに最小化できます。

## 3. タスク追加・Focus（優先タスク）・Daily Pick

### タスクの追加方法
1. **Explorerから追加**:
   - Explorer上部の入力欄、または各フォルダ横の `+` アイコン（もしくは `...` ＞ `新規タスク作成`）から、そのフォルダ直下にタスクを即座に作成できます。
2. **Timelineから直接追加（クイック追加）**:
   - Timeline上の任意のマス（特定の日時スロット、Phaseステップ、またはToDoリスト列）を**ダブルクリック**すると、その場所・日時にスケジュールされた状態でタスクを即座に追加できます。
   - 各プロジェクトレーン名の横にある `+` ボタンからもタスクを追加できます。

### Focus（最優先タスク）＆ Daily Pick
- **Focus セクション**:
  - 今すぐ集中して取り組むべき最重要タスクを `Focus`（赤い稲妻マーク ⚡）としてExplorer最上部にピックアップ表示します。
- **Daily Pick（今日のFocus選定）**:
  - Focusヘッダーの `+ Pick` ボタンをクリックすると **Daily Pick モーダル** が開き、通常のタスク一覧から今日取り組むタスクをワンクリックでFocus枠へ選出できます。
- **期限アラート表示**:
  - 締切（Deadline）が迫っているタスク（デフォルト3日以内）は黄色、期限切れのタスクは赤色の時計アイコンとバッジで自動的にハイライトされます。

## 4. Project Timeline（中央ペイン：スケジュール＆フェーズ管理）

中央の **Project Timeline** では、各プロジェクトフォルダを横方向の「レーン（行）」として並べ、タスクの実行順序やスケジュールを視覚的に管理します。

### 2つの表示モード
1. **日付基準モード (`Dates`)**:
   - カレンダーの実日付（`7日` / `14日` / `21日` 表示、`◀ 今日 ▶` 移動）を横軸にしたタイムラインです。
   - タスクの「開始日時〜締切日時」に応じたバー表示、現在時刻ライン、および繰り返しタスク（毎日・毎週など）の予定日を自動展開して表示します。
2. **カスタム期間 / ステージモード (`Custom / Stages`)**:
   - 日付に縛られない抽象的なフェーズ列（初期値: `Phase 1` 〜 `Phase 5`）で管理するモードです。
   - `+ 列を追加` でフェーズを増やしたり、列名を**ダブルクリック**して自由なステージ名（例: `企画`、`実装`、`レビュー`）に変更できます。`列構成リセット` で初期状態に戻せます。

### グリッド粒度と ToDo リスト列
- **グリッド ON / OFF と粒度設定**:
  - `Dates` モードでは **1時間 / 2時間 / 4時間 / 6時間 / 12時間 / 24時間** 単位の細かい時間グリッドを切り替えられます。
  - `Custom / Stages` モードでは、各フェーズ内を **2〜5ステップ** に細分化してタスクの前後関係を表現できます。
- **ToDo リスト列（日程未割当枠）**:
  - ツールバーの `ToDo リスト` ボタンで表示/非表示を切り替えられます。まだ日付やフェーズを決めていないタスクがフォルダごとに整理され、タイムライン側へドラッグ＆ドロップするだけでスケジュールを割り当てられます（ToDoリスト内では未完了タスクが上、完了タスクが下に自動整列されます）。
- **列幅の自由なリサイズ**:
  - `Project Lanes` 列、`ToDo リスト` 列、および各 `Phase` 列の右端をドラッグして自由に幅を調整できます（`列幅リセット` ボタンで初期幅に戻せます）。
- **実行順序の自動ナンバリング**:
  - 各プロジェクトレーン内の未完了タスクは、タイムライン上の時系列（およびToDoリストの並び）に従って自動的に優先順位が計算されます。

## 5. モバイル横画面（Fullscreen / 全体画面切り替え）

スマートフォンなどのモバイル端末でTimelineを広く閲覧・操作できるよう、**全画面モード（Fullscreen）** を搭載しています。

- **横画面（ランドスケープ）時の自動全画面化**:
  - モバイル端末を横向きにすると、自動的に最上部バー、下部ナビゲーション、Timelineツールバー（`Dates`、`Add Folder` 等）および `ToDo List` 列が非表示になり、Timeline領域が画面いっぱいに広がります（縦向きに戻すと自動で全体画面に復帰します）。
- **ワンタップで「全画面 / 全体画面」を切り替え**:
  - **タイムライン上部の日付（またはステージ）ヘッダーバーをタップ**すると、いつでも「全画面」と「全体画面」を切り替えられます。
  - **画面右下のフローティングボタン**（`全体画面` / `全画面`）や、ツールバー左上の `全画面` ボタンからもワンタップで切り替え可能です。
  - 全画面モード中の右下コントロールバーからは、全画面を維持したまま **`◀ 今日 ▶` の週移動** や **`レーン`（左側のプロジェクトレーン列）の表示/非表示切替** も行えます。
- **Fullscreen時のProject Lanes幅調整**:
  - 全画面モード中も、左側の `Project Lanes` 列（ヘッダーまたは各レーン行の右境界線）を指で左右にドラッグすることで、`56px`〜`450px` の範囲で自由に幅を調整できます。

## 6. Task & Folder Detail（右ペイン：マルチタブ＆分割詳細エディタ）

タスクまたはフォルダをクリックすると、右側の **Detail ペイン** が開きます（Dashboardだけでなく、**Archive** や **Trash** 画面でも同様に右側に表示されます）。

### マルチタブ＆最大4画面の分割表示
- **タブ管理**:
  - タスクをシングルクリックするとプレビュータブとして開き、ダブルクリックまたはピンアイコンをクリックするとタブが固定保持されます。
- **画面分割レイアウト（4種類）**:
  - Detailペイン上部のレイアウト切替ボタンから、**単一ペイン**、**左右分割 (2列)**、**上下分割 (2行)**、**2x2 グリッド分割 (4画面)** を即座に切り替えられます。
  - タブをドラッグして別の分割ペインへ移動させることも可能です。
- **幅調整・最小化**:
  - Detailペイン左端の境界線をドラッグして幅を自由に変更できます（ダブルクリックで初期幅にリセット）。
  - 右上の `－` ボタンで開いているタブを保持したまま右端のバーへ最小化でき、`×` ボタンですべてのタブを閉じます。

### タスク詳細の編集項目
- **基本設定**: タイトル、所属プロジェクトフォルダ、完了チェック、Focus切替 (⚡)、スター (★)、ピン留め (📌)
- **開始日時 & 締切日時**: 日付・時刻の指定、または `終日 (All Day)` 設定（親フォルダに締切が設定されている場合はその範囲内でバリデーションされます）
- **繰り返し設定 (Recurrence)**: `なし` / `毎日` / `N日ごと` / `毎週（曜日指定）` / `N週ごと`
- **フェーズ割当**: カスタム期間モードのステージ（Phase）とステップ位置の指定
- **関連URLリスト**: 複数のWebリンクや資料URLを登録し、ワンクリックで開けます
- **ノート / メモ**: タスクの詳細メモやチェックリストを自動保存で記述できます

### フォルダ詳細（Folder Detail）
- ExplorerやTimelineで**フォルダ名をクリック**すると、そのフォルダ専用の詳細タブが開きます。
- フォルダ全体の**締切日時（Folder Deadline）**、**フォルダメモ（Folder Notes）**、フォルダ内のタスク進捗率、および配下タスクの一覧確認・一括アーカイブ等が行えます。

## 7. Calendar / Archive / Trash（カレンダー・アーカイブ・ゴミ箱）

- **Calendar（月間カレンダー）**:
  - ワークスペース内の全タスク（締切および繰り返し予定）を月間カレンダー形式で一覧表示します。タスクをクリックして直接編集できます。
- **Archive（アーカイブ） & Trash（ゴミ箱）**:
  - 完了したタスクや不要になったタスクを、元のプロジェクトフォルダ階層を保ったままExplorer形式で閲覧・検索できます。
  - タスクを選択すると右側に **Task Detail** が開き、内容の確認・編集や元のカテゴリへの**復元 (Restore)**、**完全削除 (Permanent Delete)** が可能です。
- **自動整理（Settings ＞ Auto Sweep）**:
  - **完了タスクの自動アーカイブ**: 完了から指定日数（デフォルト **14日**）が経過したタスクを自動的にArchiveへ移動します。
  - **ゴミ箱の自動完全削除**: Trashへ移動してから指定日数（デフォルト **30日**）が経過したタスクを自動的に完全削除します。

## 8. ローカルログ同期（1日ごと・最大3ファイルの自動ローテーションバックアップ）

クラウド（Firebase Firestore）へのリアルタイム保存に加え、万が一のデータ消失に備えて **PCのローカルフォルダへ1日ごとにCSVファイルを分けて自動保存・上書きする機能** を備えています。

### 仕組みと設定方法
1. **初期設定**:
   - ヘッダー右上の `ローカル設定が必要 (Local Setting Needed)` ボタン（または `Settings` ＞ `Local folder log`）をクリックし、PC内の保存先フォルダを選択します。
2. **1日ごとの3ファイル・ローテーション保存 (`#1` → `#2` → `#3`)**:
   - 設定完了後はヘッダーに緑色の **`Sync Active`** が常時表示されます。
   - **その日の変更は同じログファイルに上書き保存**され、**翌日（次の変更日）になると次の通し番号のログファイル（`1 → 2 → 3 → 1...`）へ自動的に切り替わる** 3ファイル・ローテーション方式で最大3日分のスナップショットを保持します。
     - `NavFOR_Log_<ユーザー名>_1.csv`
     - `NavFOR_Log_<ユーザー名>_2.csv`
     - `NavFOR_Log_<ユーザー名>_3.csv`
3. **ブラウザ再起動後の自動復帰**:
   - 選択したフォルダのハンドルはブラウザの `IndexedDB` に保持されます。ブラウザ再起動後も画面操作時に権限を確認し、必要な場合はヘッダーまたはSettingsからのワンクリック承認で即座にローカル上書きが再開されます。
4. **手動CSVエクスポート / インポート**:
   - `Settings` ＞ `Data Lifecycle` から、いつでも手動でのCSVダウンロード（`Export CSV`）およびCSVからの復元（`Import CSV`）が可能です。

## 9. キーボードショートカット一覧

Explorer または Project Timeline 上でタスク・フォルダを選択している際、キーボードだけで高速に操作できます。

| キー | 動作 |
| :--- | :--- |
| `↑` `↓` `←` `→` | **Explorer**: ツリーの上下移動、フォルダの展開(`→`)/折りたたみ(`←`)<br>**Timeline**: 画面上の配置に応じた2次元空間移動（上下のレーン・左右のタスクへ移動） |
| `Space` | 選択中のタスクの **完了 / 未完了** を切り替え |
| `Enter` または `F2` | 選択中のタスクまたはフォルダの **名前をインライン変更** |
| `Escape` | インライン編集やメニューをキャンセル / 選択解除 |
| `ダブルクリック` | **Timelineの空きマス**: その日時・フェーズに新規タスクを作成<br>**タスク/フォルダ名**: 名前のインライン変更（タブは固定オープン） |

## 10. ローカル環境での起動・ビルド方法 (Run Locally)

**必要環境 (Prerequisites):** Node.js (v18以上推奨)

1. 依存パッケージのインストール:
   ```bash
   npm install
   ```
2. 開発サーバーの起動 (ポート 3000):
   ```bash
   npm run dev
   ```
3. 本番用ビルドの作成:
   ```bash
   npm run build
   ```
